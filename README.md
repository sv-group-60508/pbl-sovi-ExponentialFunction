# pbl-sovi-ExponentialFunction

A mobile-first PBL micro-game that teaches exponential functions through Sovi's growth story: viral coefficient K=0.5, churn half-life, subsidy cost floors, review storms, and launch-day planning.

- Single-file `index.html` (no build step)
- Duolingo-style 3D candy UI + Gizmo-style guided hints
- Mobile-first, one-thumb play
- Deployed on Cloudflare Pages
